# Hi, I'm Shivkumar Yadav.

I'm a **Cybersecurity enthusiast focused on Web Application Security, Penetration Testing, and DevSecOps**.

I enjoy finding vulnerabilities in web applications, understanding how they can be exploited, and helping build systems that are secure by design. My work focuses on **OWASP methodologies, VAPT, application security, API security, Secure SDLC, and CI/CD security**.

## Projects

I learn by building and breaking things.

Some of my security projects include:

* **CSRF Burp Suite Extension** — a custom extension for assisting with CSRF detection and testing.
