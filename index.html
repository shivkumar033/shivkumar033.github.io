Hi, I’m Shivkumar Yadav.

I’m a Cybersecurity enthusiast focused on Web Application Security, Penetration Testing, and DevSecOps.

I enjoy finding vulnerabilities in web applications, understanding how they can be exploited, and helping build systems that are secure by design. My work focuses on OWASP methodologies, VAPT, application security, API security, Secure SDLC, and CI/CD security.

What I Do

  • 🔐 Web Application Security & Penetration Testing
  • 🔍 Vulnerability Assessment and VAPT
  • 🛡️ OWASP Top 10 and API Security
  • ⚙️ DevSecOps and CI/CD Security
  • 🔄 Secure SDLC and Shift-Left Security

Projects

I learn by building and breaking things.

Some of my security projects include:

  • CSRF Burp Suite Extension — a custom extension for assisting with CSRF detection and testing.
  • Vulnerable Web Application — a deliberately vulnerable application for practicing exploitation, remediation, and secure coding.
  • CI/CD Security Automation — a Jenkins pipeline integrating SAST, SCA, and container security tools such as SonarQube, Snyk, and Trivy.
  • CollaboratorX — a custom Burp extension focused on DNS/HTTP callback detection.

My Learning Journey

Cybersecurity is a continuous learning process for me.

I’m currently deepening my knowledge in Web Application Security, DevSecOps, Secure SDLC, Cloud Security, Docker, Kubernetes, and AWS while strengthening my understanding of networking, Linux, automation, and modern application architectures.

I use this website to document what I learn, the security projects I build, the vulnerabilities I study, and the practical lessons I gain along the way.
